# Gaffa Docs

This repository holds the source for the [Gaffa](https://gaffa.dev) documentation site. GitBook syncs each section of the site from its own folder, as set in [`gitbook-docs.yaml`](gitbook-docs.yaml). Changes merged to `main` appear on the live site, and edits made in GitBook are committed back here.

## Sections

| Section | Live site | Folder |
| --- | --- | --- |
| Documentation | [gaffa.dev/docs](https://gaffa.dev/docs) | [`docs/`](docs/) |
| AI Tools | [gaffa.dev/docs/ai-tools](https://gaffa.dev/docs/ai-tools) | [`ai-tools/`](ai-tools/) |
| Changelog | [gaffa.dev/docs/changelog](https://gaffa.dev/docs/changelog) | [`changelog/`](changelog/) |

## Contributing a correction

- **To fix an error**, edit the page in its section folder and open a pull request against `main`.
- **To report an error**, [open an issue](https://github.com/GaffaAI/Docs/issues/new) that names the page and what is wrong.
