### Samples, Blog & Tutorials

#### Save Now, Scrape Later

We published a tutorial on using `capture_snapshot` to save an offline copy of any page, then running `parse_json`, `generate_markdown`, and other actions against it later, even after the original page has changed or disappeared. It also covers how to load lazy content with `wait` and `scroll` before you capture. [Read the blog.](https://gaffa.dev/blog/save-now-scrape-later)
